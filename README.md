## 🔬 Comprehensive Codebase Analysis & Technical Architecture

### 1. 🤖 Artificial Intelligence & Machine Learning Track
- **Location**: `1 month python ai ml/`, `python ai ml practices codes/`
- **Key Modules & Algorithms**:
  - **Supervised Machine Learning**:
    - **Decision Trees from Scratch**: Custom implementation featuring Gini Impurity calculation (`gini_impurity.py`), Shannon Entropy & Information Gain (`information_gain.py`), and Weighted Information Gain (`Weighted Information Gain.py`) driving recursive decision node splits (`tree.py`). Tested on benchmark datasets (`car.data`).
    - **Perceptron Algorithm**: Single-layer perceptron neural model (`perceptron.py`) trained on synthetic linear classification datasets (`training_set.py`).
    - **Medical Diagnostics**: Heart disease and breast cancer prediction system (`Heart-Disease-Prediction/main.py`).
    - **NLP Sentiment & Text Classification**: Multi-class text classification pipeline on BBC news data (`tezt classification/`) and text sentiment analyzer using TF-IDF vectorization and Naive Bayes (`sentiment analyssi/`).
  - **Deep Learning & Neural Networks**:
    - **LSTM Stock Price Predictor**: Sequential Long Short-Term Memory (LSTM) recurrent neural network built with Keras/TensorFlow for predicting Netflix stock prices (`stock market t/`) from historical OHLCV CSV data.
    - **Neural Machine Translation**: Sequence-to-Sequence (Seq2Seq) encoder-decoder neural translation model translating English text to Hindi (`english to hindi translation neural ml/`).
    - **Neural Architectures**: Feedforward Neural Networks (FFNN) and Recurrent Neural Networks (RNN) (`rnn_ffnn.py`, `deep_learning.py`).
  - **Unsupervised Learning**:
    - **Clustering**: K-Means clustering and hierarchical clustering algorithms (`clustering.py`, `unsuperizedlearning.py`) for customer and data segmentation.
    - **Recommendation Systems**: Movie recommendation engine (`Movie Recommand/movie_recommand.py`) computing Cosine Similarity over user-item matrices.
